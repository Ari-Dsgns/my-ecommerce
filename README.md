
# JustGoodStuff 🛍️

A responsive e-commerce web application built with React and Firebase. Designed with user experience in mind, it allows users to browse, register, manage a shopping cart, and make purchases in a clean and intuitive interface.

## 🚀 Features

- User authentication (Firebase Auth)
- Real-time cart and product management (Firestore)
- Responsive layout (Mobile-first)
- Product filtering and search
- Conditional rendering and lazy loading
- Basic form validation and error handling

## 🛠️ Tech Stack

- React
- Firebase Auth & Firestore
- JavaScript (ES6)
- CSS3
- Vite (for development)
